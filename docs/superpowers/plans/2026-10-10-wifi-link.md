# WiFi Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the Waveshare AMOLED-2.16 show Claude Code usage by polling the Anthropic API itself over WiFi/HTTPS, with no laptop, daemon, or BLE data link, while every existing build stays byte-for-byte in behaviour.

**Architecture:** A small transport interface (`link.h`) sits between `main.cpp`/`ui.cpp` and the data source. `link_ble.cpp` adapts today's `ble.cpp` GATT data service; `link_wifi.cpp` runs a FreeRTOS poller that POSTs a 1-token Haiku request, reads the `anthropic-ratelimit-unified-*` headers, and emits the exact JSON the daemon emits today, so `parse_json`, usage-rate, chime and UI logic are untouched. Provisioning is a captive portal + serial commands backed by NVS. Selection is per PlatformIO env through `build_src_filter` and a `-DLINK_WIFI` flag.

**Tech Stack:** Arduino-ESP32 core 3.x (pioarduino 55.03.38-1): `WiFi`, `WiFiClientSecure`, `HTTPClient`, `WebServer`, `DNSServer`, `Preferences`; NimBLE-Arduino 2.x (HID kept); ArduinoJson 7; mbedTLS; host `g++` for pure-logic unit tests.

**Spec:** `docs/superpowers/specs/2026-10-10-wifi-link-design.md`

## Global Constraints

- No `#ifdef BOARD_*` in shared code. The only new compile-time switch is `LINK_WIFI`, and it may appear only inside `ble.cpp` (to compile out the data GATT service). Everything else selects by `build_src_filter`.
- No new `lib_deps`. `WiFi`, `WiFiClientSecure`, `HTTPClient`, `WebServer`, `DNSServer`, `Preferences` ship with the Arduino core.
- The device never calls any OAuth token or refresh endpoint. The only outbound request is `POST https://api.anthropic.com/v1/messages`.
- The device never prints the full token to serial or renders it on screen. Serial `status` shows length and the last 4 characters only.
- The WiFi payload uses the daemon's JSON schema verbatim: keys `s, sr, w, wr, st, acct, tp, pd, rd, t, tf, c, ok`.
- Payload `t` is a *local* wall-clock epoch (UTC epoch + tz offset), matching the daemon; the UI reads it with `gmtime_r`.
- Poll interval 60 s on success; failures double the interval up to 300 s; the next HTTP 200 resets it to 60 s.
- TLS roots: GTS Root R4 K1 and K2 concatenated, verified with `setCACert`. Never `setInsecure()`.
- mbedTLS allocations ≥ 512 B go to PSRAM; the poller task stack (12 288 bytes) is allocated in PSRAM.
- Softap SSID is exactly `Clawdmeter`, open (no password), portal at `192.168.4.1`.
- Target boards: only envs with `-DBOARD_HAS_PSRAM`. C6 envs must not include `link/wifi/`.
- Existing envs (`waveshare_amoled_216`, `_18`, `_206`, `_216_c6`, `_18_c6`, `lcd_154`, `lcd_4`, `sim`) must build after every task.
- Commit after every task with a conventional-commit message and the `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` trailer.

## Review Focus

1. **A reset timestamp in the past** (`anthropic-ratelimit-unified-5h-reset` < now) must yield `sr: 0`, never a negative number. Pinned in Task 3 test `should_clamp_reset_in_past_to_zero`.
2. **Enterprise reset on the 31st of a month** whose previous month is shorter (e.g. 31 Mar → 28 Feb) must not overflow into the wrong month. Pinned in Task 3 test `should_clamp_previous_month_day_for_short_months`.
3. **A payload longer than the BLE receive buffer** (`BLE_BUF_SIZE`) is irrelevant for WiFi, but `link_get_data()` on WiFi must never return a partially written buffer while the poller writes it. Pinned in Task 6 by the mutex-guarded double buffer and the `should_not_publish_until_complete` reasoning check in step 6.
4. **A password containing `&`, `+`, `%` or quotes** entered in the portal form must be stored verbatim. `WebServer::arg()` URL-decodes form-encoded bodies, and the form must therefore POST as `application/x-www-form-urlencoded` (default). Pinned in Task 5 hardware step by provisioning with password `a&b+c%d"e`.
5. **A wrong token (HTTP 401)** must not reopen the captive portal (which would drop the user's WiFi credentials prompt into a loop); it must show the 401 hint and keep backing off. Pinned in Task 6 hardware step.

```cpp
#pragma once
#include <stdbool.h>

// Transport abstraction between main/ui and the usage-data source.
// Two implementations exist, selected per PlatformIO env via build_src_filter:
//   link/link_ble.cpp   — host daemon writes JSON over the custom BLE GATT service
//   link/wifi/*         — the device polls the Anthropic API itself over WiFi/HTTPS
// Shared code must only ever include this header, never a transport's own.

enum link_state_t {
    LINK_INIT,          // not yet started
    LINK_WAITING,       // BLE: advertising. WiFi: portal open / connecting / no success yet
    LINK_CONNECTED,     // BLE: central connected. WiFi: STA up and >=1 successful poll
    LINK_DISCONNECTED,  // BLE: central dropped. WiFi: STA lost after having been connected
};

// Snapshot of what the UI should say about the transport. Pointers are to
// static storage owned by the transport and remain valid until the next
// link_status() call.
struct LinkStatus {
    link_state_t state;
    const char*  line1;   // hint title shown when not connected, e.g. "To pair"
    const char*  line2;   // hint body line 1
    const char*  line3;   // hint body line 2
    const char*  detail;  // short error / context, "" when none
};

void        link_init(void);
void        link_tick(void);
LinkStatus  link_status(void);

// JSON usage payload in the daemon's schema. link_get_data() clears the
// pending flag; the returned pointer is valid until the next link_tick().
bool        link_has_data(void);
const char* link_get_data(void);
void        link_ack(void);
void        link_nack(void);
void        link_request_refresh(void);

// Hold-to-pair gesture completed (PWR held ~3 s then released).
// BLE: clear bonds and re-advertise. WiFi: reopen the captive portal.
void        link_on_pair_gesture(void);

// Give the transport first refusal on a serial command line. Returns true if
// it consumed the line. BLE handles nothing; WiFi handles ssid/pass/token/...
bool        link_serial_cmd(const char* line);
```

// Mirrors daemon/claude-usage-daemon.sh build_payload_for_token().

struct RateLimitHeaders {               // raw header values, "" when absent
    const char* util_5h;   const char* reset_5h;   const char* status_5h;
    const char* util_7d;   const char* reset_7d;
    const char* status;                             // anthropic-ratelimit-unified-status
    const char* overage_util; const char* overage_reset;
};

struct PayloadOptions {
    long now_utc;      // seconds since epoch, UTC
    int  tz_minutes;   // local offset east of UTC (e.g. 60 for UTC+1)
    int  hour_fmt;     // 12 or 24; 0 = omit clock fields
};

// Returns false (and writes "{\"ok\":false}") when neither a 5h nor an
// overage utilization header is present. `out` is always NUL-terminated.
bool usage_payload_build(const RateLimitHeaders& h, const PayloadOptions& o,
                         char* out, size_t cap);

#include "link/wifi/usage_payload.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>

// ---- small civil-calendar helpers (UTC; tz applied by caller) -------------
static bool is_leap(int y) { return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0; }
static int  days_in_month(int y, int m) {           // m = 1..12
    static const int d[] = { 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };
    return (m == 2 && is_leap(y)) ? 29 : d[m - 1];
}
// Howard Hinnant's days_from_civil: days since 1970-01-01 for y-m-d.
static long days_from_civil(int y, int m, int d) {
    y -= m <= 2;
    const long era = (y >= 0 ? y : y - 399) / 400;
    const unsigned yoe = (unsigned)(y - era * 400);
    const unsigned doy = (153 * (m + (m > 2 ? -3 : 9)) + 2) / 5 + d - 1;
    const unsigned doe = yoe * 365 + yoe / 4 - yoe / 100 + doy;
    return era * 146097 + (long)doe - 719468;
}
static void civil_from_days(long z, int* y, int* m, int* d) {
    z += 719468;
    const long era = (z >= 0 ? z : z - 146096) / 146097;
    const unsigned doe = (unsigned)(z - era * 146097);
    const unsigned yoe = (doe - doe / 1460 + doe / 36524 - doe / 146096) / 365;
    const long yy = (long)yoe + era * 400;
    const unsigned doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    const unsigned mp = (5 * doy + 2) / 153;
    *d = (int)(doy - (153 * mp + 2) / 5 + 1);
    *m = (int)(mp < 10 ? mp + 3 : mp - 9);
    *y = (int)(yy + (*m <= 2));
}

static int round_pct(double util) { return (int)lround(util * 100.0); }
static long mins_until(long reset, long now) {
    if (reset <= 0) return 0;
    double m = (double)(reset - now) / 60.0;
    return m > 0 ? lround(m) : 0;
}

bool usage_payload_build(const RateLimitHeaders& h, const PayloadOptions& o,
                         char* out, size_t cap) {
    if (!out || cap == 0) return false;
    out[0] = '\0';

    char clock[48] = "";
    if (o.hour_fmt == 12 || o.hour_fmt == 24)
        snprintf(clock, sizeof clock, ",\"t\":%ld,\"tf\":%d", o.now_utc + (long)o.tz_minutes * 60, o.hour_fmt);

    if (h.util_5h && *h.util_5h) {
        // Pro / Max: 5h + 7d windows
        int  sp = round_pct(atof(h.util_5h));
        long sr = mins_until(atol(h.reset_5h ? h.reset_5h : "0"), o.now_utc);
        int  wp = (h.util_7d && *h.util_7d) ? round_pct(atof(h.util_7d)) : 0;
        long wr = mins_until(atol(h.reset_7d ? h.reset_7d : "0"), o.now_utc);
        const char* st = (h.status_5h && *h.status_5h) ? h.status_5h : "unknown";
        snprintf(out, cap,
            "{\"s\":%d,\"sr\":%ld,\"w\":%d,\"wr\":%ld,\"st\":\"%s\",\"acct\":\"pro\"%s,\"c\":1,\"ok\":true}",
            sp, sr, wp, wr, st, clock);
        return true;
    }

    if (h.overage_util && *h.overage_util) {
        // Enterprise: spending limit over a calendar-monthly period that ends
        // at overage_reset. Period start = same day/time one month earlier
        // (clamped to the shorter month), computed in *local* time like the
        // daemon's datetime.fromtimestamp.
        int  sp = round_pct(atof(h.overage_util));
        long reset = atol(h.overage_reset ? h.overage_reset : "0");
        long sr = mins_until(reset, o.now_utc);
        const char* st = (h.status && *h.status) ? h.status : "unknown";

        int tp = 0, pd = 30;
        char rd[12] = "";
        if (reset > 0) {
            long off = (long)o.tz_minutes * 60;
            long lreset = reset + off;
            long days = lreset / 86400; if (lreset % 86400 < 0) days--;   // floor
            long secs = lreset - days * 86400;
            int y, m, d; civil_from_days(days, &y, &m, &d);
            int pm = (m == 1) ? 12 : m - 1;
            int py = (m == 1) ? y - 1 : y;
            int pdd = d < days_in_month(py, pm) ? d : days_in_month(py, pm);
            long lstart = days_from_civil(py, pm, pdd) * 86400 + secs;
            long len = lreset - lstart;
            if (len > 0) {
                double pct = (double)((o.now_utc + off) - lstart) / (double)len * 100.0;
                int t = (int)lround(pct);
                tp = t < 0 ? 0 : t > 100 ? 100 : t;
                pd = (int)lround((double)len / 86400.0);
            }
            static const char* MON[] = { "Jan","Feb","Mar","Apr","May","Jun","Jul","Aug","Sep","Oct","Nov","Dec" };
            snprintf(rd, sizeof rd, "%s %d", MON[m - 1], d);
        }
        snprintf(out, cap,
            "{\"s\":%d,\"sr\":%ld,\"w\":0,\"wr\":0,\"st\":\"%s\",\"acct\":\"ent\",\"tp\":%d,\"pd\":%d,\"rd\":\"%s\"%s,\"c\":1,\"ok\":true}",
            sp, sr, st, tp, pd, rd, clock);
        return true;
    }

    snprintf(out, cap, "{\"ok\":false}");
    return false;
}

static const char* NS = "wifi";

void prov_load(WifiConfig* out) {
    memset(out, 0, sizeof *out);
    Preferences p;
    if (!p.begin(NS, /*readOnly=*/true)) return;
    p.getString("ssid",  out->ssid,  sizeof out->ssid);
    p.getString("pass",  out->pass,  sizeof out->pass);

    Preferences p;
    p.begin(NS, false);
    p.putString("ssid",  c.ssid);
    p.putString("pass",  c.pass);
    p.putString("token", c.token);
    p.putInt("tz", c.tz_minutes);
    p.putInt("tf", c.hour_fmt);
    p.end();
}

void prov_clear(void) {
    Preferences p;
    p.begin(NS, false);
    p.clear();
    p.end();
}

bool prov_has_token(const WifiConfig& c) { return c.token[0] != '\0'; }

static void copy_arg(char* dst, size_t cap, const char* src) {
    while (*src == ' ') src++;
    strncpy(dst, src, cap - 1);
    dst[cap - 1] = '\0';
    // trim trailing whitespace
    size_t n = strlen(dst);
    while (n && (dst[n-1] == ' ' || dst[n-1] == '\t')) dst[--n] = '\0';
}

static void print_status(const WifiConfig& c) {
    size_t tl = strlen(c.token);
    Serial.printf("wifi: ssid=\"%s\" pass=%s token=%s(%u chars%s%s) tz=%+d min hourfmt=%d\n",
        c.ssid, c.pass[0] ? "set" : "unset",
        tl ? "set" : "unset", (unsigned)tl,
        tl >= 4 ? ", ends " : "", tl >= 4 ? c.token + tl - 4 : "",
        c.tz_minutes, c.hour_fmt);
}

bool prov_handle_serial(const char* line, WifiConfig* cfg) {
    if (strncmp(line, "ssid ", 5) == 0)       { copy_arg(cfg->ssid,  sizeof cfg->ssid,  line + 5); prov_save(*cfg); Serial.println("ssid saved — reboot to apply"); return true; }
    if (strncmp(line, "pass ", 5) == 0)       { copy_arg(cfg->pass,  sizeof cfg->pass,  line + 5); prov_save(*cfg); Serial.println("pass saved — reboot to apply"); return true; }
    if (strncmp(line, "token ", 6) == 0)      { copy_arg(cfg->token, sizeof cfg->token, line + 6); prov_save(*cfg); Serial.println("token saved — reboot to apply"); return true; }
    if (strncmp(line, "tz ", 3) == 0)         { cfg->tz_minutes = atoi(line + 3); prov_save(*cfg); Serial.printf("tz=%d saved\n", cfg->tz_minutes); return true; }
    if (strncmp(line, "hourfmt ", 8) == 0)    { int v = atoi(line + 8); cfg->hour_fmt = (v == 12 || v == 24) ? v : 0; prov_save(*cfg); Serial.printf("hourfmt=%d saved\n", cfg->hour_fmt); return true; }
    if (strcmp(line, "status") == 0)          { print_status(*cfg); return true; }
    if (strcmp(line, "wifi-reset") == 0)      { prov_clear(); memset(cfg, 0, sizeof *cfg); Serial.println("wifi credentials cleared — rebooting"); delay(200); ESP.restart(); return true; }
    return false;
}

#include "link/wifi/wifi_poller.h"
#include "link/wifi/provisioning.h"
#include "link/wifi/captive_portal.h"
#include "link/wifi/usage_payload.h"

#include <Arduino.h>
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <HTTPClient.h>
#include <esp_heap_caps.h>
#include <mbedtls/platform.h>
#include <freertos/FreeRTOS.h>
#include <freertos/task.h>
#include <freertos/semphr.h>
#include <time.h>
#include <string.h>

static const char* API_URL   = "https://api.anthropic.com/v1/messages";
static const char* API_BODY  = "{\"model\":\"claude-haiku-4-5-20251001\",\"max_tokens\":1,\"messages\":[{\"role\":\"user\",\"content\":\"hi\"}]}";
static const uint32_t POLL_MS_MIN = 60000, POLL_MS_MAX = 300000;
static const int      CONNECT_FAILS_TO_PORTAL = 3;
static const time_t   SANE_EPOCH = 1704067200;   // 2024-01-01

static const char* HDRS[] = {
    "anthropic-ratelimit-unified-5h-utilization",
    "anthropic-ratelimit-unified-5h-reset",
    "anthropic-ratelimit-unified-5h-status",
    "anthropic-ratelimit-unified-7d-utilization",
    "anthropic-ratelimit-unified-7d-reset",
    "anthropic-ratelimit-unified-status",
    "anthropic-ratelimit-unified-overage-utilization",
    "anthropic-ratelimit-unified-overage-reset",

static WifiConfig          s_cfg;

static volatile bool       s_payload_ready = false;
static StackType_t*        s_stack;
static StaticTask_t        s_tcb;

// Route big mbedTLS buffers (TLS record buffers are 16 KB each) to PSRAM so
// NimBLE and the TLS session can coexist in internal SRAM.
static void* tls_calloc(size_t n, size_t sz) {
    void* p = nullptr;
    if (n * sz >= 512) p = heap_caps_calloc(n, sz, MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT);
    if (!p)            p = heap_caps_calloc(n, sz, MALLOC_CAP_INTERNAL | MALLOC_CAP_8BIT);
    return p;
}

static void publish(const char* json) {
    xSemaphoreTake(s_mutex, portMAX_DELAY);
    strncpy(s_payload, json, sizeof s_payload - 1);
    s_payload[sizeof s_payload - 1] = '\0';
    s_payload_ready = true;
    xSemaphoreGive(s_mutex);
}

// One API round-trip. Returns true on HTTP 200 with a usable payload.
static bool poll_once() {
    WiFiClientSecure tls;
    tls.setCACert(GTS_ROOT_R4_CA);
    tls.setTimeout(15);
    HTTPClient http;
    http.setTimeout(15000);
    http.setReuse(false);
    if (!http.begin(tls, API_URL)) { s_error = "TLS error"; return false; }
    http.addHeader("Authorization", String("Bearer ") + s_cfg.token);
    http.addHeader("anthropic-version", "2023-06-01");
    http.addHeader("anthropic-beta", "oauth-2025-04-20");
    http.addHeader("Content-Type", "application/json");
    http.setUserAgent("Clawdmeter-wifi/1.0");
    http.collectHeaders(HDRS, sizeof HDRS / sizeof HDRS[0]);

    int code = http.POST((uint8_t*)API_BODY, strlen(API_BODY));
    if (code <= 0) { s_error = "No network"; http.end(); return false; }

    String v[8];
    for (int i = 0; i < 8; i++) v[i] = http.header(HDRS[i]);
    http.end();

    // Rate-limit headers arrive on 200 *and* on 429 (limit exceeded); use both.
    if (code == 401)                     { s_error = "Bad token (401)"; return false; }
    if (code != 200 && code != 429)      { static char e[24]; snprintf(e, sizeof e, "API error %d", code); s_error = e; return false; }

    RateLimitHeaders h = { v[0].c_str(), v[1].c_str(), v[2].c_str(), v[3].c_str(),
                           v[4].c_str(), v[5].c_str(), v[6].c_str(), v[7].c_str() };
    PayloadOptions o = { (long)time(nullptr), s_cfg.tz_minutes, s_cfg.hour_fmt };
    char out[320];
    if (!usage_payload_build(h, o, out, sizeof out)) { s_error = "No usage headers"; return false; }
    publish(out);
    s_error = (code == 429) ? "Rate limited (429)" : "";
    Serial.printf("wifi: poll ok (%d) heap=%u psram=%u\n", code,
        (unsigned)heap_caps_get_free_size(MALLOC_CAP_INTERNAL),
        (unsigned)heap_caps_get_free_size(MALLOC_CAP_SPIRAM));
    return true;
}

static void enter_portal() {
    s_phase = POLLER_PORTAL;
    WiFi.disconnect(false);
    portal_start(s_cfg);
    while (true) { portal_tick(); vTaskDelay(pdMS_TO_TICKS(5)); }   // /save restarts the device
}

static void task(void*) {
    if (!prov_has_wifi(s_cfg)) enter_portal();

    WiFi.mode(WIFI_STA);
    WiFi.setSleep(false);
    WiFi.setHostname("clawdmeter");
    uint32_t interval = POLL_MS_MIN;

    for (;;) {
        if (s_portal_req) enter_portal();

        if (WiFi.status() != WL_CONNECTED) {
            s_phase = POLLER_CONNECTING;
            WiFi.begin(s_cfg.ssid, s_cfg.pass);
            uint32_t t0 = millis();
            while (WiFi.status() != WL_CONNECTED && millis() - t0 < 20000 && !s_portal_req) vTaskDelay(pdMS_TO_TICKS(100));
            if (WiFi.status() != WL_CONNECTED) {
                s_error = "No network";
                if (++s_conn_fails >= CONNECT_FAILS_TO_PORTAL && !s_success) enter_portal();
                vTaskDelay(pdMS_TO_TICKS(5000));
                continue;
            }
            s_conn_fails = 0;
            Serial.printf("wifi: connected to %s ip=%s\n", s_cfg.ssid, WiFi.localIP().toString().c_str());
            configTime(0, 0, "pool.ntp.org", "time.google.com");
        }

        if (time(nullptr) < SANE_EPOCH) {
            s_phase = POLLER_WAIT_TIME;
            s_error = "Waiting for time";
            vTaskDelay(pdMS_TO_TICKS(500));
            continue;
        }

        s_phase = POLLER_POLLING;
        if (!prov_has_token(s_cfg)) { s_error = "No token — hold PWR to set up"; vTaskDelay(pdMS_TO_TICKS(5000)); continue; }

        if (poll_once()) { s_success = true; interval = POLL_MS_MIN; }
        else             { interval = interval * 2 > POLL_MS_MAX ? POLL_MS_MAX : interval * 2; Serial.printf("wifi: poll failed (%s), next in %lus\n", s_error, (unsigned long)interval / 1000); }

        for (uint32_t waited = 0; waited < interval && !s_portal_req; waited += 250) vTaskDelay(pdMS_TO_TICKS(250));
    }
}

void poller_start(const WifiConfig& cfg) {
    s_cfg = cfg;
    s_mutex = xSemaphoreCreateMutex();
    mbedtls_platform_set_calloc_free(tls_calloc, free);
    const uint32_t STACK_WORDS = 12288 / sizeof(StackType_t);
    s_stack = (StackType_t*)heap_caps_malloc(12288, MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT);
    if (!s_stack) s_stack = (StackType_t*)malloc(12288);
    xTaskCreateStaticPinnedToCore(task, "wifi_poll", STACK_WORDS, nullptr, 1, s_stack, &s_tcb, 0);
}

void poller_request_portal(void)  { s_portal_req = true; }
poller_phase_t poller_phase(void) { return s_phase; }
bool  poller_had_success(void)    { return s_success; }
const char* poller_error(void)    { return s_error; }
int   poller_connect_failures(void) { return s_conn_fails; }
bool  poller_has_payload(void)    { return s_payload_ready; }

bool poller_take_payload(char* dst, size_t cap) {
    xSemaphoreTake(s_mutex, portMAX_DELAY);
    bool had = s_payload_ready;
    if (had) { strncpy(dst, s_payload, cap - 1); dst[cap - 1] = '\0'; s_payload_ready = false; }
    xSemaphoreGive(s_mutex);
    return had;
}
